使用说明

登录与权限

管理员在「账号管理」里添加同事的手机号并分配角色；同事用手机号+密码登录。管理员初始账号：13800000000，密码：admin123，登录后请立即修改密码和手机号。

角色：管理员 = 全部权限；编辑 = 可录入和修改数据；只读 = 只能查看；样衣专员 = 只能看和编辑样衣表。管理员还可以在「账号管理 → 设置可见表格」里给每个账号单独勾选能看到的表格（例如只勾「样衣表」，对方登录后顶部统计和其他页面都不会出现）。管理员可以修改所有人的手机号、重置密码，也可以看到当前密码（明文保存）。任何人登录后都可以点右上角「修改我的密码」自己改密码。

SKU 规则（重点）

SKU 格式如 LF-JK-002-BR-L（品牌-款式-款号-颜色-尺码）。「耗用规则」里只填前三个字段，例如 LF-JK-002；气泡袋、磨砂袋、领标按它匹配。尺码标不需要设置：系统自动取销售表 SKU 的最后一段（S/M/L/XL）对应「尺码标 S/M/L/XL」。样衣成本先按完整 SKU 匹配，匹配不到再按前三个字段匹配。

样衣表 / 辅料表 / 选项设置

样衣表按产品、SKU、图片、供应商、成本价、售价、供应商库存、尺码、模特、颜色、件数、到货、寄还、面料、卖点、附件、运费等完整记录；供应商、模特、颜色这些下拉选项在「选项设置」里维护，可随时增删。「辅料表」记录采购参考（MOQ、单价、店铺链接），与「辅料库」的库存是两回事。

多商品订单

一个订单号可以填多个 SKU：点「＋ 添加商品」继续加行。总价 = 各 SKU 单价×数量之和（不含运费）。运费单独填，只参与利润计算。

汇率

「汇率设置」里维护每日 USD→CNY 汇率；销售表单价填 USD，系统按下单日期自动换算成 CNY 单价并计算总价。

利润

利润 = 总价(CNY) − 样衣成本 − 运费。样衣成本在「样衣表」录入，成本找不到的订单会标「待补成本」，不计入累计利润。

售后表

记录退款、退货、补发、换货等售后单，可上传售后图片；各选项按固定下拉填写。

数据保存与访问

  • 数据保存在运行本程序的电脑上（data 文件夹），所有同事通过同一个网址访问，数据实时同步。
  • 同事访问方式：和你在同一个网络下，浏览器打开启动时显示的「局域网访问」地址。
  • 要让不同网络（线上办公、出差）也能访问：需要把程序部署到有公网地址的云服务器上，或使用内网穿透工具（ngrok / cpolar / 花生壳），详见文件夹里的 README.txt。
  • 建议定期点「导出备份」；换电脑时复制整个文件夹即可迁移。
